# 字段字典与指标口径

`A股典型个股行情` 的列名由 `tencent_stock` 处理器统一产出为英文，本文逐字段给出中文含义与单位，避免在复盘与报表中误读数值。

## 一、字段总表

| 字段名 | 中文含义 | 单位/格式 | 口径说明 |
| --- | --- | --- | --- |
| symbol | 标的代码 | 字符串 | 市场前缀（sh/sz）加 6 位数字代码，唯一标识一只股票 |
| stock_name | 股票名称 | 字符串 | 接口返回的证券简称，用于展示与分组 |
| current_price | 最新价 | 元 | 快照时刻的成交价，保留两位小数 |
| change_percent | 涨跌幅 | % | 相对上一交易日收盘价的涨跌比例，正为涨、负为跌 |
| open_price | 开盘价 | 元 | 当日集合竞价形成的开盘价 |
| high_price | 最高价 | 元 | 当日截至采集时刻的最高成交价 |
| low_price | 最低价 | 元 | 当日截至采集时刻的最低成交价 |
| volume_lots | 成交量 | 手 | 1 手等于 100 股，接口原始单位为手，未再换算为股 |
| amount_wan | 成交额 | 万元 | 当日累计成交金额，接口返回单位即为万元 |
| total_mv | 总市值 | 亿元 | 总股本乘以最新价，包含未流通股份 |
| circulating_mv | 流通市值 | 亿元 | 流通股本乘以最新价，是换手率的分母 |
| turnover_rate | 换手率 | % | 成交量除以流通股本，衡量筹码交换活跃度 |
| amplitude | 振幅 | % | （最高价减最低价）除以上一交易日收盘价 |
| timestamp | 采集时间 | YYYY-MM-DD HH:MM:SS | 写入该行快照的时刻，采集间隔 60 秒 |

## 二、容易混淆的三组口径

1. 价格类：`current_price`、`open_price`、`high_price`、`low_price` 均为绝对价格，单位是元；其中最高价与最低价是“截至采集时刻”的日内极值，盘中仍会继续变化。
2. 规模类：`volume_lots` 是股数口径（手），`amount_wan` 是金额口径（万元），`total_mv` 与 `circulating_mv` 是市值口径（亿元）。三者不可相互替代。
3. 比率类：`change_percent` 以昨收为基准，`turnover_rate` 以流通股本为基准，`amplitude` 以昨收为基准；分母不同，数值大小不可跨口径直接比较。

> 所有比率字段在接口侧已经是百分数，展示时直接加 `%` 后缀，不要再乘以 100。

## 三、分布视图的字段用法

`行情分布概览` 是一个图表视图，用三种图形同时观察字段分布：

- 柱状图：以 `stock_name` 为维度、`change_percent` 为度量（取均值），用于横向比较个股涨跌；
- 直方图：对 `turnover_rate` 自动分箱，观察换手率的集中区间与长尾；
- 散点图：以 `amount_wan` 为横轴、`turnover_rate` 为纵轴，判断放量与高换手是否同步。

## 四、使用提醒

- 字段值来自实时快照，采集间隔 60 秒，同一交易日内多次查看结果可能不同；
- 市值与换手率依赖流通股本，除权除息日附近需留意数值跳变；
- 数据仅供研究参考，不构成投资建议。
