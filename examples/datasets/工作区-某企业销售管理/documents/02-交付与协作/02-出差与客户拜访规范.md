# 出差与客户拜访规范

本文规范出差申请、客户拜访记录与费用报销的填写要求，保证「出差统计」表可作为客户接触的完整台账。

## 出差事项分类

- **项目交付**：现场实施、上线支持、验收。
- **客户拜访**：例行走访、需求调研、关系维护。
- **技术支持**：故障处理、性能调优。
- **商务洽谈**：合同、续约、招投标。

## 记录要求

| 字段 | 要求 |
|---|---|
| 出差事项 | 从上述四类中选择，不要自造类别 |
| 出差日期 | 以实际到达客户现场日期为准 |
| 出差地点 | 精确到城市 + 客户名称 |
| 参与人员 | 多人以顿号分隔，与员工表姓名一致 |
| 交流内容 | 记录客户诉求与结论，不写流水账 |

> 未在出差统计中登记的拜访，不计入客户接触频次考核。

## 费用与审批

1. 出差前在系统提交申请，注明预计天数与预算。
2. 差旅费用按财务制度标准执行，超标部分需事前审批。
3. 返程后 5 个工作日内提交拜访记录与报销单据。

客户拜访中发现的交付风险，请同步登记到 [[日常待办协作机制]]；项目级问题参见 [[产品开发交付流程]]，整体口径见 [[销售管理总览]]。
