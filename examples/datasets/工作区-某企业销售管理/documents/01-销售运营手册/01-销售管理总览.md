# 销售管理总览

本工作区承载「某企业销售管理」的经营数据与协作规范，服务销售运营、客户成功与交付团队。所有分析口径、流程规范与复盘结论统一沉淀在文档中，避免口头约定造成理解偏差。

## 工作区数据资产

| 数据表 | 用途 | 更新频率 |
|---|---|---|
| 电商销售 | 订单级交易明细 | 每日 |
| 客户流失 | 客户行为与流失标签 | 每月 |
| 营销活动 | 渠道投放与转化 | 活动结束后 |
| 产品开发 | 交付项目进度 | 每周 |
| 出差统计 | 客户拜访与交流记录 | 每次出差 |
| 日常待办 | 团队任务跟踪 | 每日 |
| 部门表 / 员工表 | 组织与人力底表 | 变更时 |

## 使用约定

1. 引用数据时优先使用本文档中的视图区块，筛选条件与排序口径已在视图内固化。
2. 指标定义调整时先更新对应文档，再修改视图配置，保证文档与视图一致。
3. 涉及客户信息的分析结论文档仅在工作区内流转，不导出到外部渠道。

> 数据说明：订单「销售额」单位为元，「合同金额」单位为万元，跨表对比前请先统一单位。
