# 数据使用须知

本文件是工作区「某地区数据」的使用约定，适用于所有查阅与引用数据的同学。字段含义见 [[数据集说明与字段字典]]，采集与质检见 [[气温天气采集与质检规范]]，建模口径见 [[房价预测建模口径]]，分析结论见 [[分析报告]] 文件夹。

## 一、授权范围

- 允许：在本组织内部用于分析、建模、汇报与教学演示。
- 允许：在内部报告中引用统计结果，并标注数据表名称与统计口径。
- 禁止：向外部第三方转发原始明细数据或可还原明细的导出文件。
- 禁止：将数据用于个人画像、营销触达或任何形式的商业转售。
- 超出以上范围的使用，需先取得数据治理组的书面授权。

## 二、脱敏说明

1. 气温天气表不含个人身份信息，城市粒度公开度较高。
2. 房价预测表已移除房源编号、小区名称与联系方式等可定位字段。
3. 数值字段做过分位裁剪，极端值已按规则处理或剔除。
4. 布尔字段以 1/0 表示，不保留原始文本描述。
5. 数据不包含经纬度精确坐标，无法反推具体门牌。

## 三、引用规范

- 引用时必须写明数据表名、时间范围与统计口径，例如「2024 年逐日气温」。
- 引用分析结论时请注明来源文档标题，便于追溯。
- 对外口径以本工作区最新版本文档为准，禁止使用过期截图。
- 派生指标的换算方式需在报告中一并说明，避免口径歧义。

> 任何与本文档冲突的旧版本引用，均以最新发布版本为准。

## 四、更新频率

| 数据对象 | 更新频率 | 说明 |
| --- | --- | --- |
| 气温天气 | 每日 | 拉取前一日数据，质检后发布 |
| 房价预测 | 每周 | 房源快照刷新，去重后入库 |
| 分析报告 | 每月 | 月度分析随数据更新重新生成 |
| 使用须知 | 按需 | 授权或口径变化时即时更新 |

## 五、问题反馈

- 数据缺失或异常：联系气象数据小组或数据建模组。
- 口径歧义：由数据治理组统一裁定并更新文档。
- 权限申请：说明用途、范围与期限，走内部审批流程。
