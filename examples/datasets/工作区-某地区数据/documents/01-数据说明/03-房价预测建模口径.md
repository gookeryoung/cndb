# 房价预测建模口径

本文件约束基于 `房价预测` 表的全部建模工作，保证不同同学产出的模型可比、可复现。字段定义见 [[数据集说明与字段字典]]，数据质量规则见 [[气温天气采集与质检规范]] 中同类处理原则，结果解读见 [[房价影响因素分析]]。

## 一、样本范围

- 城市：仅纳入广州、杭州等在册城市，样本量过少的城市单独标注。
- 面积：剔除面积小于 20 平米或大于 400 平米的极端记录。
- 价格：剔除房价明显偏离同城同面积分位区间的记录，避免录入错误干扰。
- 时间：以当前快照为准，不做跨年混合口径比较。
- 去重：同一房源重复挂牌时保留最新一条。

## 二、目标变量

- 主目标：`房价_万元`，即房源总价，建模时一般取对数后再拟合。
- 辅助目标：单价 = `房价_万元 * 10000 / 面积_平米`，单位为元每平米。
- 目标变量不允许在特征中出现派生的等价形式，避免信息泄漏。

## 三、特征工程

| 特征 | 来源字段 | 处理方式 |
| --- | --- | --- |
| 面积 | 面积_平米 | 连续值，直接入模并做分箱对照 |
| 房间数 | 房间数 | 整数，可派生「户均面积」 |
| 房龄 | 房龄_年 | 连续值，0 表示新房 |
| 距市中心 | 距市中心_km | 连续值，可做分段哑变量 |
| 近地铁 | 是否近地铁 | 1/0 哑变量 |
| 学区房 | 是否学区房 | 1/0 哑变量 |
| 楼层 | 楼层 | 连续值，低层与高层分组 |
| 城市 | 城市 | 独热编码或目标编码 |

- 派生特征示例：户均面积 = 面积_平米 / 房间数。
- 缺失值按列填充中位数，并在模型中加缺失指示变量。
- 类别型变量统一在训练集上拟合编码映射，再应用到验证集。

## 四、评估口径

1. 划分方式：按城市分层抽样，训练集与测试集比例约 8 比 2。
2. 主指标：测试集上的绝对百分比误差中位数。
3. 辅指标：决定系数与平均绝对误差，单位统一为万元。
4. 对照基线：同城同面积分位中位数，模型需稳定优于基线。
5. 每次评估记录随机种子与数据版本号，便于复盘。

## 五、交付要求

> 模型结论必须同时给出误差区间与适用边界，禁止只报单一最优分数。

- 提交物包括特征清单、评估报告与预测样例。
- 特征口径调整视为口径变更，需同步更新本文档。
- 分析结论统一落到 [[房价影响因素分析]]，便于业务方直接查阅。
