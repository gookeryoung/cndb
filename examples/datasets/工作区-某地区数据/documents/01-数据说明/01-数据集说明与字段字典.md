# 数据集说明与字段字典

本工作区「某地区数据」面向区域气候观察与住宅价格研究，当前纳管两张核心数据表：`气温天气` 与 `房价预测`。本文件是这两张表的统一口径入口，字段含义、单位与取值边界均以本文件为准；采集与质检细则见 [[气温天气采集与质检规范]]，建模口径见 [[房价预测建模口径]]。工作区文档按 [[数据说明]]、[[分析报告]] 两个文件夹组织。

## 适用范围与使用前提

- 气温天气：以城市为观测主体，覆盖 2024 年逐日记录，用于气候分布、极端天气与城市对比分析。
- 房价预测：以房源为观测主体，覆盖多城市在售与成交样本，用于价格影响因子分析与建模。
- 两张表均不包含个人身份信息，字段均为结构化数值或枚举值。
- 任何对外口径的引用，都应同时标明数据表名与统计时间范围。

## 气温天气字段字典

| 字段 | 含义 | 单位 | 取值范围与说明 |
| --- | --- | --- | --- |
| 日期 | 观测自然日 | 日期 | 2024-01-01 起的逐日日期，主键之一 |
| 城市 | 观测城市 | 文本 | 泸州、北京等城市名称，主键之一 |
| 最高温_℃ | 当日最高气温 | 摄氏度 | 约 -20 ~ 45，须大于等于最低温 |
| 最低温_℃ | 当日最低气温 | 摄氏度 | 约 -30 ~ 40，须小于等于最高温 |
| 湿度_% | 当日平均相对湿度 | 百分比 | 0 ~ 100 闭区间 |
| 风速_m/s | 当日平均风速 | 米每秒 | 大于等于 0 |
| 天气 | 天气现象 | 枚举 | 晴、多云、阴、小雨、中雨、大雨、雷阵雨、雪等 |

## 房价预测字段字典

## 字段使用约定

1. 所有数值字段均以半角下划线连接单位后缀，查询与建模时不要重复换算单位。
2. 布尔字段以 1/0 存储，展示层再映射为「是/否」，不要在中间层写成文本。
3. 单价按 `房价_万元 * 10000 / 面积_平米` 换算为元每平米，保留两位小数。
4. 缺失值一律保持为空，不使用 0 或 -1 填充；异常值处理见 [[气温天气采集与质检规范]]。

> 字段口径如需变更，必须先由数据治理组更新本文件，再同步下游分析与模型，避免同名不同义。
