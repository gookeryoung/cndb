# 气温天气采集与质检规范

本规范面向 `气温天气` 表的采集、入库与质检环节，供数据工程与质检同学执行。字段含义与单位请先阅读 [[数据集说明与字段字典]]，本文件只约束「数据怎么来、怎么判合格」。

## 一、采集来源与时间粒度

- 来源：区域气象服务接口的逐日观测摘要，按城市分别拉取后合并为宽表。
- 粒度：城市 × 日期，一天一条，不保留小时级明细。
- 时区：统一按北京时间归档，日期以观测结束日归属，不跨日拆分。
- 增量：每日 06:00 拉取前一日数据，历史回补走全量重刷，不做手工改数。
- 入库前对城市名称做白名单校验，未登记城市直接拒收并告警。

## 二、必备字段与非空要求

| 字段 | 是否必填 | 缺失处理 |
| --- | --- | --- |
| 日期 | 是 | 缺失即整行拒收 |
| 城市 | 是 | 缺失即整行拒收 |
| 最高温_℃ | 是 | 缺失进入待补队列，不落主表 |
| 最低温_℃ | 是 | 缺失进入待补队列，不落主表 |
| 湿度_% | 否 | 允许缺失，允许为空 |
| 风速_m/s | 否 | 允许缺失，允许为空 |
| 天气 | 否 | 缺失标记为「未知」 |

## 三、异常值判定与处理

1. 逻辑矛盾：最高温小于最低温，判定为严重异常，整行废弃并回源重取。
2. 湿度越界：湿度不在 0 至 100 闭区间内，按越界处理，置空并记入质检日志。
3. 风速为负：风速小于 0 属采集噪声，置空处理；风速不小于 0 方可保留。
4. 极值筛查：最高温高于 45 摄氏度或低于 -20 摄氏度时人工复核后再入库。
5. 日期重复：同一城市同一天出现多行时保留更新时间最新的一条，其余标记为重复。

## 四、质检流程与产出

- 每日跑一轮规则校验，规则命中明细写入质检日志表，保留 90 天。
- 通过率低于 98% 时暂停当日发布并通知值班同学。
- 连续三日无数据的城市触发链路告警，需排查接口可用性。
- 通过质检的数据标注 `qc=passed`，未通过的仅进入内部排查视图。

## 五、常见问题

> 遇到「整月缺失」先确认接口分页是否被截断，再确认城市编码是否变更，不要直接补 0 或补均值。

- 湿度偶尔整列为空，多为上游传感器维护窗口，属正常现象。
- 天气枚举新增取值时，需同步更新 [[数据集说明与字段字典]] 中的枚举清单。
- 质检规则调整必须留版本号，并在此文档追加变更记录。
