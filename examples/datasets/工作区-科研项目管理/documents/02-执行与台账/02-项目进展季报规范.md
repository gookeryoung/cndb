# 项目进展季报规范

季度报告是项目过程管理的核心台账，用于掌握研究进度、识别风险、支撑经费拨付与中期检查。所有在研项目均须按季度填报，报告数据同步录入项目进展台账，作为结题验收的重要依据。

## 填报周期

1. 报告季度按自然季度划分，即 Q1（1—3 月）、Q2（4—6 月）、Q3（7—9 月）、Q4（10—12 月）。
2. 填报截止时间为季度结束后 10 个工作日内，遇法定节假日顺延。
3. 立项当期不足一个季度的，从下一完整季度开始填报。
4. 已进入验收结题阶段的项目，填报至结题报告提交当季为止。

> 连续两个季度未填报的项目，系统自动标记为异常，暂停经费拨付并列入重点跟踪名单。

## 字段口径

| 字段 | 填写口径 | 示例 |
| --- | --- | --- |
| 报告季度 | 年度 + Qn，不得跨季度合并 | 2024Q2 |
| 进展阶段 | 立项启动 / 技术攻关 / 中期检查 / 临床验证 / 系统集成 / 性能优化 / 海试验证 / 放大制备 / 验收结题 / 结题后续 | 技术攻关 |
| 进度百分比 | 累计完成比例，取 0—100 的整数，不得低于上一季度 | 82 |
| 关键成果 | 本季度可核验的产出，量化描述 | 发表 SCI 论文 2 篇 |
| 存在问题 | 客观描述，无问题填"无" | 模型在小样本场景表现不佳 |
| 下一步计划 | 与问题对应的具体措施 | 引入迁移学习方法改进 |
| 报告日期 | 实际提交日期，格式 YYYY-MM-DD | 2024-06-30 |

进度百分比应与阶段匹配：立项启动一般不超过 20%，技术攻关为 20%—70%，验收结题为 90% 以上。

## 审核要求

- 课题负责人对报告内容真实性负责，签字后提交。
- 承担单位科研秘书核对课题编号、报告季度与进度逻辑，1 个工作日内完成初审。
- 科研管理处复审，重点关注进度异常、成果标注与经费执行匹配度。
- 审核不通过的退回修改，退回次数超过 2 次的纳入年度考核记录。
- 涉及重大调整、阶段性失败的，须附情况说明并报处务会研究。

## 归档衔接

季度报告电子稿与审核记录随项目结题一并归档，具体材料清单与目录规范见[[里程碑与成果归档]]，归档目录模板参见[[归档模板]]。项目整体的立项、执行与结题管理框架见[[科研项目管理总览]]。

## 数据质量要求

- 同一课题同一季度的记录唯一，重复提交以最后一次审核通过的版本为准。
- 关键成果与成果形式须能对应项目考核指标，否则不计入结题统计。
- 问题描述应避免笼统表述，不得使用"进展顺利""按计划推进"等无信息量描述。
