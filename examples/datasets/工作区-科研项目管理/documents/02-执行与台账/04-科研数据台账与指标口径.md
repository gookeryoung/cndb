# 科研数据台账与指标口径

本工作区的数据按「项目主体 + 人员 + 经费 + 进展」四本台账组织，四本台账通过课题编号关联，任何一方变更须同步更新。本页统一说明各表用途、指标口径以及预置的视图与分析模板，供填报人和评审专家对照使用。

## 四本台账

| 台账 | 一行代表 | 主键 | 与其他台账的关系 |
| --- | --- | --- | --- |
| 科研项目 | 一个立项课题 | 课题编号 | 主表；向其余三表回填项目状态、项目类别 |
| 课题负责人 | 一位负责人（或骨干）在一个课题上的角色 | 负责人编号 | 按课题编号关联科研项目 |
| 科研经费 | 某课题下某个预算科目的一次拨付记录 | 经费编号 | 按课题编号关联科研项目 |
| 项目进展 | 某课题某个季度的进展报告 | 课题编号 + 报告季度 | 按课题编号关联科研项目 |

## 关键指标口径

| 指标 | 口径 | 用途 |
| --- | --- | --- |
| 项目级别 | 国家级 / 省部级 / 市级 / 校级 | 判断资源能级，按级别比较经费投入与产出 |
| 计划周期_月 | 任务书约定的执行月数 | 计算计划结束季度，识别逾期风险 |
| 经费总额_万元 | 各预算科目预算金额之和（须严格相等） | 经费规模口径，禁止手填凑数 |
| 论文数 / 专利数 | 项目执行期内已登记（含已录用）的成果数 | 产出规模口径，结题前须与成果登记一致 |
| 合作单位数 | 任务书列明的联合承担单位数量 | 衡量协同复杂度 |
| 经费执行率 | 已支金额 ÷ 预算金额（分析模板中为 `exec_rate`） | 识别执行偏慢与超支科目 |
| 产出效率 | 论文数 ÷ 经费总额 × 1000（`paper_per_million`） | 每千万元经费的论文产出，用于横向比较 |

> 经费总额与科目预算之和的差额超过 0.05 万元即视为台账错误，须退回承担单位调整后再提交。

## 预置视图

- 科研项目：`全部` / `在研项目` / `已结题项目` / `高产出项目`（论文数 ≥ 8）/ `大额项目榜`（经费 ≥ 300 万元）；
  看板按`项目类别`、`项目状态`、`项目级别`分组；`结题日历` 按结题日期铺排；`科研项目经费概览` 与 `项目投入产出` 提供图表视角。
- 课题负责人：`PI名录`（是否 PI = 是）、`按职称看板`、`职称分布占比`。
- 科研经费：`未结清经费`、`待拨付清单`、`超支预警`、`拨付日历`、`经费投入矩阵`（项目类别 × 拨付年份）。
- 项目进展：`里程碑达成`（验收结题）、`延期整改进展`、`按进展阶段看板`、`进展阶段进度分布`（箱线图）。

## 预置分析模板

分析模块已预置四个模板，可直接「分析列表」打开后修改复用：

1. **项目产出效率**（科研项目）：散点图看经费与论文产出的关系，分组汇总按项目类别比较平均产出效率。
2. **按级别的经费与产出**（科研项目）：按项目级别汇总项目数、经费合计与专利合计，判断资源是否向高能级项目集中。
3. **经费执行率分布**（科研经费）：直方图看各预算科目执行率的集中区间，分组汇总给出已拨合计与平均执行率。
4. **阶段进度分布**（项目进展）：箱线图比较各阶段进度离散程度，用于季度例会讲评。

## 数据维护要求

- 新增课题须先入科研项目台账，再补负责人、经费与首季进展，避免出现无主表的孤立记录。
- 项目状态变更（在研 → 延期整改 → 已结题 / 已中止）由科研管理处统一修改，承担单位不得自行调整。
- 每季度末由承担单位科研秘书核对本单位人员与经费执行数据，核对结果在季度报告中留痕。
- 台账变更遵循统一的字段维护时限，人员信息维护要求见[[课题负责人名录说明]]；经费执行细则见[[科研经费管理办法]]；进展填报口径见[[项目进展季报规范]]；结题与归档要求见[[里程碑与成果归档]]。
