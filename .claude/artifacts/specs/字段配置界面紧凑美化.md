# 计划：表设置「字段」配置界面紧凑美化

## 概要

将表设置（及 GridPage 字段管理弹窗共用）的字段配置界面按既有 `.ts-*` 紧凑风格统一改造：字段列表由平铺 Table 改为类型图标行卡片、编辑字段弹窗紧凑化、类型专属配置区卡片化、选项编辑器行距收紧，并清除触及区域的硬编码颜色（改用 `var(--cn-*)` 主题变量，兼容暗色/多主题）。仅动渲染层，不改动任何表单逻辑、数据同步与保存语义。

## 现状分析

- 入口两处共用同一组件：[TableSettingsModal.tsx](file:///f:/Dev/cndb/frontend/src/pages/modals/TableSettingsModal.tsx)（embedded Tab 模式）与 [GridPage.tsx:1160](file:///f:/Dev/cndb/frontend/src/pages/grid/GridPage.tsx)（独立 Modal 模式），核心渲染全部在 [FieldManager.tsx](file:///f:/Dev/cndb/frontend/src/pages/modals/FieldManager.tsx)。
- 现有问题：
  1. **字段列表**（L253-305）：plain antd Table，与同弹窗「视图」Tab 已有的 `.ts-view-row` 行卡片风格不一致，无类型图标。
  2. **编辑字段弹窗**（L308-372，720px）：必填/唯一/隐藏三个 Checkbox 各占一整列且 label 在上方，纵向空间浪费大。
  3. **ConfigEditor**（L676-779）：虚线分隔线裸排，无卡片容器；日期类 `auto_fill` Radio.Button 文案过长（"创建时填入当前时间"）挤压布局。
  4. **SelectOptionsEditor**（L931-1004）：行距松散；硬编码 `#999`、`#d9d9d9` 等在暗色主题下不可读。
- 既有可复用范式：index.css 中 `.ts-stats` / `.ts-view-row` / `.ts-view-icon`（`var(--cn-border)`、`var(--cn-bg-*)`、hover 高亮 brand 色）。
- 测试无 UI 结构依赖：TableSettingsModal.test.tsx 只测权限/基本信息；tagColors 相关测试只测纯函数。改造不受测试约束。

## 改动方案

### 1. `frontend/src/index.css` — 新增 `.fm-*` 样式类

紧跟现有 `.ts-*` 区块后新增（复用同款视觉语言，全部走 `var(--cn-*)`）：

- `.fm-toolbar`：顶部统计+按钮条（替代 inline flex）。
- `.fm-row`：字段行卡片（对齐 `.ts-view-row`：padding 8px 12px、border、radius 8、hover 边框变 brand 色）+ `.fm-row-icon`（26px 图标座，对齐 `.ts-view-icon`）+ `.fm-row-name` + `.fm-row-actions`。
- `.fm-config-section`：类型专属配置卡片（`background: var(--cn-bg-muted)`、`border: 1px solid var(--cn-border)`、radius 8、padding 12）+ `.fm-config-title`（12px、`var(--cn-text-secondary)`）。
- `.fm-option-row` / `.fm-option-empty`：选项编辑行（gap 6、紧凑）与空态虚线框。

### 2. `frontend/src/pages/modals/FieldManager.tsx` — 渲染层改造

**A. 新增字段类型图标映射** `FIELD_TYPE_ICONS`（FontSizeOutlined / AlignLeftOutlined / CheckSquareOutlined / HashtagOutlined / PercentageOutlined / CalendarOutlined / ClockCircleOutlined / FieldTimeOutlined / TagOutlined / TagsOutlined / MailOutlined / LinkOutlined / PhoneOutlined / ApartmentOutlined / PaperClipOutlined）。

**B. 字段列表**（`fieldListContent`）：antd Table → `.fm-row` 行卡片列表
- 行结构：`[类型图标] [名称(粗体，PK 行前加 gold PK Tag)] [类型 Tag] [必填 Tag(orange)] [隐藏 Tag] …… [编辑] [删除(Popconfirm)]`，操作按钮右对齐。
- 空列表时显示 Empty；外层加 `maxHeight + overflowY: auto`（列表长时可滚动，嵌入 Tab 已有滚动容器，保持自然）。
- 工具栏改用 `.fm-toolbar`，文案不变。

**C. 编辑字段弹窗**（`editDialog`）
- width 720 → 640。
- Row 1 保留：字段名 span 12 / 类型 span 12。
- Row 2 紧凑化：必填、唯一、隐藏三个 Checkbox 改为内联文字形式（`<Form.Item name="required" valuePropName="checked" style={{ marginBottom: 0 }}><Checkbox>必填</Checkbox></Form.Item>`，无上方 label），与「默认值」Input 同行排布（Col span 约 4/4/6/10，实现时微调）。
- 不触碰 `openDialog`/`closeDialog`/`handleSubmit` 及 setTimeout 挂载时序逻辑。

**D. ConfigEditor**
- 外层虚线裸排 → `.fm-config-section` 卡片 + `.fm-config-title`（带 SettingOutlined）。
- 日期类 `auto_fill` Radio.Button 文案缩短为「不自动 / 创建时 / 更新时」，extra 说明保留原语义（"创建时填入当前时间；更新时覆盖"）。
- 数字/link/attachment 保持 Row/Col 结构，Form.Item 统一 `marginBottom: 8` 收紧。
- `#d9d9d9` 等硬编码色随类化消除。

**E. SelectOptionsEditor**
- 行结构不变（序号/标签输入/推荐/色块/取色器/删除），改用 `.fm-option-row`，gap 8 → 6，控件 size small 保持。
- 空态改 `.fm-option-empty`；`#999` → `var(--cn-text-muted)`。
- **同步/推荐/自动配色全部逻辑函数（syncToForm、updateOption、handleSmartSuggest* 等）零改动**，仅动 return JSX。

### 3. 范围外（明确不做）

- importDialog（从其他表引入）本次不动，仍保留硬编码色；列为遗留可选项。
- 不新增拖拽排序等未要求功能。

## 假设与决策

- 「各类字段的配置界面」= 字段 Tab 下的列表 + 新建/编辑字段弹窗 + 类型专属配置区 + 选项编辑器；importDialog 属独立引入流程，不计入本次范围。
- 字段列表由 Table 改行卡片：与「视图」Tab 既有风格一致，且当前 Table 未用到排序/筛选能力，改造成本低、观感收益大。
- 样式落 index.css 类而非 inline style：跟随 `.ts-*` 既有约定，保证多主题/暗色适配。
- embedded 与独立 Modal 两种模式经同一 JSX 自动同时生效，无需分支处理。
