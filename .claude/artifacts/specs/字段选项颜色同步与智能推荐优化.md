# 字段选项颜色同步与智能推荐优化方案

## 摘要

解决四个问题：
1. 数据表展示的字段选项标签颜色（自动解析所得）未同步到【表设置 → 编辑字段】对话框
2. 单选项智能推荐颜色时第 4 项与第 1 项重复（推荐规则无列表感知）
3. 编辑字段选项列表增加【全部智能推荐】一键配色按钮
4. 默认导入数据时选项自动智能配色，并与编辑字段保持同步

## 现状分析（基于代码探索）

### 数据流

- **表格渲染**（[GridCell.tsx:193-207](file:///f:/Dev/cndb/frontend/src/pages/grid/components/GridCell.tsx#L193-L207)、KanbanView.tsx:139）：调用 `resolveTagColor(value, options, index)`，优先级：已存 color → 语义推荐 → 分级调色板 fallback。
- **编辑字段对话框**（[FieldManager.tsx](file:///f:/Dev/cndb/frontend/src/pages/modals/FieldManager.tsx) `SelectOptionsEditor`）：只显示 `config.options[].color` **已存**颜色，无色则显示空白。
- **后端**（[smart_color.py](file:///f:/Dev/cndb/src/cndb/plugins/tables/field_types/smart_color.py)）：`suggest_colors(labels)` 已实现列表级配色（语义优先 + 分级调色板避重）；`SelectFieldConfig` 校验器在建表时自动为空 color 填色（types.py:374-417）；导入合并 `_merge_new_options`（field_ops.py:337-391）为新选项配色。

### 四个问题的根因

| # | 现象 | 根因 |
|---|------|------|
| 1 | 表格已显示颜色，编辑字段里却是空白 | ① 选项未存 color 时表格走语义/调色板 fallback 显示，编辑字段只认已存色；② `resolveTagColor` 的 fallback index 由调用方传（单选不传恒 0，多选传单元格内位置 i），同一选项在不同行/不同视图颜色不一致，编辑字段无法复现 |
| 2 | 依次点击智能推荐，第 4 项与第 1 项重复 | `handleSmartSuggest`（FieldManager.tsx:877-887）用 `suggestColorForLabel ?? getTagColorName`，hash fallback 无列表感知，13 色板下 4 项约 1/3 概率撞色；语义同义项也会重复但属正确 |
| 3 | 缺一键全部推荐 | 选项编辑器头部只有【添加选项】按钮（FieldManager.tsx:891-896），无批量推荐入口 |
| 4 | 导入数据时配色/同步疑虑 | 后端建表校验器与导入合并已自动配色；缺口：`_merge_new_options` 只对新增 label 调 `suggest_colors`，不避开**已有选项已占用**的颜色；存量无色选项打开编辑字段不会自动补色显示 |

## 改动方案

### 前端 1：`frontend/src/utils/tagColors.ts`

1. **`resolveTagColor` fallback index 稳定化**：当 value 命中 options 数组中某选项（无论 string 还是 {label,value,color} 对象）且该选项无已存 color 时，调色板 fallback index 改用**该选项在 options 中的位置 pos**（而非调用方传入的 index）；未命中任何选项时才用调用方 index。效果：同一选项在单选/多选/看板中颜色恒定，且可被编辑字段复现。现有测试中按调用方 index 断言的用例需同步调整（值未命中 options 时行为不变）。
2. **新增 `suggestColorsForLabels(labels: string[]): string[]`**：镜像后端 `suggest_colors`——语义优先（允许语义同义项重复，如"已完成/通过"都绿），未命中项按分级调色板 fallback 且**避开已用颜色**（used 集合含语义命中色与先前 fallback 色），调色板耗尽后循环。纯函数不写缓存。

### 前端 2：`frontend/src/pages/modals/FieldManager.tsx`（SelectOptionsEditor）

1. **加载时自动补色**（修问题 1 的对话框侧）：`normalizeOptionsFromConfig` 归一化后，对 color 为空的选项调用 `resolveTagColor(label, 原始options, pos)` 补色（与表格完全同源），对话框即刻显示与表格一致的颜色；保存时随 `syncToForm` 落库，实现永久同步。
2. **单选项推荐列表感知**（修问题 2）：`handleSmartSuggest(key)` 与 `updateOption` 的 label 变更自动配色，均改为：对当前选项列表全部 label 调 `suggestColorsForLabels`，取本选项槽位的颜色。
3. **新增【全部智能推荐】按钮**（修问题 3）：选项列表头部【添加选项】左侧添加按钮，图标 `BgColorsOutlined`，文案"全部智能推荐"；点击对全部非空 label 选项应用 `suggestColorsForLabels`（覆盖式，与后端 `apply_smart_colors(overwrite=True)` 语义一致），空 label 选项保留预分配色；全部 label 为空时 `message.info('请先输入显示标签')`。

### 后端 1：`src/cndb/plugins/tables/field_types/smart_color.py`

`suggest_colors(labels, used_colors: set[str] | None = None)` 增加可选参数：初始 used 集合合并传入色，fallback 避开它们。默认 None 行为不变（向后兼容）。

### 后端 2：`src/cndb/plugins/tables/field_ops.py`

`_merge_new_options`（:337-391）：调用 `suggest_colors` 时传入已有选项已占用的颜色集合，使导入追加的新选项避开存量颜色（修问题 4 的一致性缺口）。prefill/sync 两条导入链路自动受益。

### 问题 4 说明

后端导入链路已默认智能配色：建表（SelectFieldConfig 校验器 types.py:374-417）→ 文件导入（FileImportPreview 传 string[]，后端校验时填色）→ 行导入（prefill_select_options_from_rows / sync_select_options_from_table → _merge_new_options）。本次补齐避重缺口 + 端到端测试；前端问题 1 的"打开编辑字段自动补色"保证存量无色字段与表格即刻同步。

## 测试计划

### 前端（vitest，`frontend/src/utils/tagColors.test.ts` 扩展）

- `resolveTagColor`：命中选项时 fallback 用选项自身位置（多选不同行内顺序不影响同选项取色）；未命中时仍用调用方 index。
- `suggestColorsForLabels`：语义优先；≥4 个无语义 label 颜色互不重复（问题 2 回归）；语义同义项允许重复；与后端 `suggest_colors` 结果一致（同输入同输出）。
- 空列表/空 label 边界。

### 后端（pytest）

- `tests/test_smart_color.py`：`suggest_colors` 新增 `used_colors` 参数行为（避开传入色；None 兼容旧调用）。
- `tests/test_fields_import.py` 或 `test_field_types.py`：`_merge_new_options` 新选项颜色不与已有选项重复；含 options 建表后读取 config 每个选项 color 非空（导入 → 编辑字段同步断言）。

## 决策与假设

- 问题 1 的"数据表已设置颜色"理解为：表格视图展示的自动解析色（语义/调色板 fallback）。网格各视图无手动设色入口（已搜索确认），编辑字段是唯一设色 UI。
- 【全部智能推荐】为覆盖式（重配全部非空选项，含手动已设色），与后端 overwrite=True 对齐；用户显式点击才触发，不静默覆盖。
- 语义同义项颜色重复属正确行为（"已完成/通过"同为绿色），不做避重；仅 fallback 路径避重。
- 不改 `getTagColorName`（hash）本身：link 标签、日历等场景仍依赖它；仅选项推荐链路不再用 hash。

## 验证步骤

1. `make check`（lint + typecheck + cov 全绿；含 frontend-check 前端门禁）。
2. 手动回归路径：
   - 编辑已有 select 字段（存量无色选项）→ 打开编辑字段，颜色应与表格一致；保存后重新打开仍在。
   - 新建 select 字段，输入 4+ 个无语义标签，逐个点智能推荐 → 颜色互不重复。
   - 点【全部智能推荐】→ 所有选项按语义/避重重新配色。
   - 文件导入建表（含 select 列）→ 编辑字段中选项均带色；向已有表导入含新枚举值的行 → 新选项带色且不与旧选项撞色。
