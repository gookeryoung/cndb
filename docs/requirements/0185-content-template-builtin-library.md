## 附录 A：第一批内置模板（「科研项目管理」）

分类 `research-pm`：名称「科研项目管理」，排序 10，说明「立项 → 执行 → 结题全过程的文档骨架」。

通用口径（所有内置模板一致）：

- 正文从 `## 一、…` 起，不写一级标题（文档标题由「从模板新建」时用户填写）；
- 只含纯 Markdown：标题、段落、列表、`- [ ]` 复选项、表格；**不得含** `{{table:…}}`、`[[双链]]`、工作区 / 文档 / 用户 id 等任何工作区相关引用；
- 需要填写的位置统一用 `（填写）` 或表格空单元格，不写示例值冒充数据；
- 中文序号「一、二、」按业务习惯排列，避免与导出模板自动编号叠加。
