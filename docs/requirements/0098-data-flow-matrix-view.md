# 需求卡片：数据流程 UI 改为「一级过程 × 二级子过程」矩阵视图

- 编号：0098
- 来源 / 提出人：用户（会话 2026-11-04）
- 日期：2026-11-04
- 关联 ADR：无（S1，纯前端 UI 重构；数据流程接口 / 数据模型不变，沿用 ADR 0097）

> 本卡片是**需求原文与约束编号的唯一副本**：需求变更后先改这里，再改代码。

## 需求原句（逐字）

> 参考此图改造数据流程UI为矩阵式，设计独立的组件实现，默认显示一级过程，支持二级过程展开。和具体内容列表独立开，避免显示重叠

（配图：横向大过程 × 纵向子过程矩阵式流程图，见图例：主流程推进 / 子过程顺序 / 跨阶段延续）

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「改造数据流程UI为矩阵式」 | 页面主视图改为矩阵：横向列 = 一级过程（`flows[]`），纵向行 = 二级子过程（`steps[]`）；列头展示流程名 / 描述 / 子过程数 / 表单数 / 记录数，列间用箭头串联，横向可滚动；同一行号在不同列对齐 | `frontend/src/pages/dataFlow/DataFlowMatrix.tsx`、`frontend/src/index.css` | 组件单测：列头渲染、子过程按行渲染、展开列行对齐；窄屏横向滚动 |
| C2 | 「设计独立的组件实现」 | 矩阵抽成独立受控组件 `DataFlowMatrix`（props：flows / activeFlowKey / activeStepKey / expandedKeys / onToggleFlow / onSelectStep / onExpandAll / onCollapseAll），页面只负责状态与数据；组件不包含表单 CRUD 逻辑 | 同上 | 组件单测独立渲染，不需要路由 / 查询 Provider |
| C3 | 「默认显示一级过程，支持二级过程展开」 | 初始只渲染一级过程列头，不渲染任何子过程；点击列头展开 / 收起该列的子过程，可同时展开多列；提供「展开全部 / 收起全部」；展开后子过程带序号（1.1 / 1.2）、表单 / 审批节点标识，选中子过程高亮 | 同上 + `DataFlowPage.tsx` | 页面单测：默认无子过程节点；点击列头出现子过程；全部展开 / 收起 |
| C4 | 「和具体内容列表独立开，避免显示重叠」 | 矩阵与子过程内容区是两个块级区段（普通文档流，无跨块绝对定位 / 浮层）：矩阵在上，内容区在下，内容区自带标题（流程 / 子过程 / 序号）与独立工具栏（搜索 / 新建 / 记录数）+ 表格；矩阵收起不影响内容区 | `DataFlowPage.tsx`、`DataFlowMatrix.tsx`、`index.css` | 页面单测：`data-flow-table` 在 `data-flow-content` 内、不在 `data-flow-matrix` 内；收起全部后内容区仍在 |
| C5 | 「数据 CRUD 不受影响」 | 沿用 0095/0097：有表单子过程可列表 / 搜索 / 新建 / 编辑 / 删除；无表单子过程展示审批 / 确认空态，不提供 CRUD | `DataFlowPage.tsx` | 既有 CRUD / 搜索 / 审批节点用例继续通过 |
| C6 | （响应式与主题） | 断点沿用已登记 `767.98px`；配色走列色调（蓝 / 绿 / 橙 / 紫 / 青），弱色底用 rgba 不依赖 `color-mix`；间距 / 字号 / 圆角只走 `--cn-*` token | `frontend/src/index.css` | `tokens.test.ts` 通过；Chrome 81 兼容链无新增 `color-mix` |
| C7 | （工程口径） | 不新增接口 / 数据模型；CHANGELOG / CONTEXT 同步；前端全量测试通过 | 文档 | `make flow` |
