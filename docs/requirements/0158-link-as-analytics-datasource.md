## 需求原句（逐字）

> 可以

承接口径（ADR 0154 交接，2026-11-25）：

> 下一步：无（本期收尾）。若要继续：P3.2 另立 ADR；或把链接接入分析页 / 文档 `{{table:}}` 引用（均属新增授权面，须先评审）

生产场景：总部已通过工作区链接拿到各部门的只读数据（P0-P3.1 落地），但**只能在只读网格里翻页看**，没法做汇总——「各部门销售额按月汇总」「投诉率 Top N」这类每月重复的分析仍要人工导 CSV 再算。本期把链接接进分析页，让跨工作区数据能直接进模板。

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「链接作为分析数据源」 | 分析模板的数据源可由「本工作区表」扩展为「本工作区表 ∪ 我可见的工作区链接」；选择链接后按该链接的字段 / 视图口径建指标与分组 | `analytics` + `workspaces`（links） | 接口测试 + 模板配置校验 |
| C2 | （承接 0154 L1 / H15） | **不新增授权面**：每次执行分析时重新解析链接（`resolve_link`）与源工作区权限；无权 → 该数据源报错（403 文案指向源工作区拥有者），**不静默返回空数据** | `workspaces/services/links.py` | 判定层单测：撤回 / 过期 / 非成员 → 明确失败 |
| C3 | （H17 字段隐藏） | 聚合与分组**只能使用链接可见字段**；隐藏字段不得出现在指标、分组、筛选、排序、图表标签任何位置 | `analytics` | 接口测试：隐藏字段用于公式 / 分组 → 400 |
| C4 | （H15 行级） | 行级读范围与只读网格完全一致（同一 `list_rows` 口径）；若做 SQL 下推聚合，**必须带同一 WHERE**（含默认档与命中规则） | `analytics` | 判定层单测：规则外行不计入聚合 |
| C5 | （可解释） | 模板保存时记录**数据源描述**（本表 / 链接 id + 别名 + 源工作区名）；打开模板时展示来源与到期；失效数据源给可执行提示 | `analytics` + 前端 | 单测 + e2e 文案 |
| C6 | （不传递权限） | 模板可共享，但**权限不随模板走**：他人打开模板按其自身权限执行；无权数据源 fail-closed，不降级成「空结果」也不回退到创建者的权限 | `analytics` | 接口测试：创建者有权 / 打开者无权 → 403 |
| C7 | （缓存一致） | 分析结果缓存键必须含 `user_id` + `link_id` + 链接口径签名；链接撤回 / 过期 / 源数据写入后结果不得命中旧缓存 | `analytics` + `core/cache` | 单测：撤回后同参数不再返回缓存 |
| C8 | （导出边界） | 分析导出（CSV / PNG）与页面展示同一数据口径；CSV 受 `EXPORT_MAX_ROWS` 与列裁剪约束 | `analytics` | 接口测试 |
| C9 | （MVP 范围） | 只允许**单个数据源**执行；多链接 union 汇总与跨工作区 join 留后续期，需再评审 | `analytics` | 模板校验：多数据源 → 400 |
| C10 | （不引入继承） | 链接的链接、链接再进 lookup / 流水线 / 文档 `{{table:}}` 引用仍不允许（沿用 0154 L5） | 全局 | 接口测试 |

## 现状影响面（候选，待 ADR 核实）

| # | 疑似受影响能力 | 候选位置 | 备注 |
