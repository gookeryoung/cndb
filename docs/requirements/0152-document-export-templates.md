# 需求卡片：模板板块与文档导出模板

> 需求原文与约束编号 C1..Cn 的唯一副本在本卡片，ADR 只引用不复制（H26）。

- 编号：0152（S2：新增数据表 + 新增端点 + 备份格式 + 导出契约变化）
- 来源 / 提出人：用户（会话 2026-11-25）
- 日期：2026-11-25
- 关联 ADR：`docs/adr/0152-document-export-templates.md`（Proposed，待评审）

## 需求原句（逐字）

> 增加模板板块，在大模型设置右侧。首先增加文档模板，针对生成word实现字体、标题、段落等可配置化，目标是md生成的word符合企业规范。提供论文、报告等内置模板。

## 澄清结论（需求方 2026-11-25 回复）

| # | 问题 | 结论 |
|---|---|---|
| 1 | 模板归属与内置清单 | **工作区级**；内置 8 套：标准（= 现状默认）、研究报告、技术报告、趋势分析、论文、公文、周报、宣传报道 |
| 2 | 是否兼顾 PDF | **尽可能一套模板同时兼顾 PDF**（同一份配置既渲染 docx 也渲染 pdf，PDF 侧按可用字体与排版能力降级） |
| 3 | 配置项范围 | 按最佳实践补全（见 C3，含页面 / 页眉页脚 / 正文 / 标题与编号 / 表格与题注 / 列表与代码） |

### C3 明细（配置项，★ = 本期必做，☆ = 同期增强）

| 组 | 配置项 |
|---|---|
| 页面与页眉页脚 | ★ 纸张（A4 / A3 / Letter）、页边距（上 / 下 / 左 / 右，cm）；★ 页脚页码（关闭 / `1` / `第 X 页` / `第 X 页 共 Y 页`）、页眉文字、首页不同；☆ 页眉页脚字号 |
| 正文段落 | ★ 西文字体 / 中文字体、字号、加粗、颜色、对齐（左 / 居中 / 右 / 两端）；★ 行距（倍数或固定磅值）、段前 / 段后（pt）、首行缩进（字符）、孤行控制；☆ 字间距（pt）、段落「与下段同页」 |
| 标题与编号 | ★ H1–H6 逐级：中 / 西文字体、字号、加粗、颜色、对齐、段前段后、首行缩进；★ 标题编号（无 / `1` `1.1` `1.1.1` / `第一章` / `一、`）；☆ 标题「与下段同页」、大纲级别 |
| 表格与题注 | ★ 表头底色 / 文字色 / 加粗、表格字体与字号、表格边框色；★ 表头跨页重复、单元格垂直对齐；☆ 三线表（学术 / 公文常用）、斑马纹；☆ 图表题注（`图 1` / `图 1-1` 编号、题注字体字号、位置在上 / 在下） |
| 列表与代码 | ★ 列表缩进与段后间距；★ 代码块字体 / 字号 / 底色 / 边框；☆ 列表符号样式（项目符号 / 数字 / 中圆点）、代码块左侧强调条 |

非目标（明确不做，避免误期）：目录（TOC）自动生成、页眉企业 LOGO 图片、双栏排版、脚注 / 尾注样式、封面页模板。
