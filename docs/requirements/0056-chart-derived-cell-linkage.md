# 需求卡片：图表设计器派生单元格联动（柱线双轴次值默认留空）

> 本卡片是**需求原文与约束编号的唯一副本**：ADR 只引用 C1..Cn，不复制原文；需求澄清后先改这里，再同步 ADR「口径」表。

## 需求原句（逐字）

> 文档，插入图表，柱线组合图（双轴），数据第二列次值默认均留空。第二列第一行次值默认不能填入。如果填入第二列次值，则对应主值随之变动。把主动修改的和受影响的值进行区分，便于用户知晓。其他图表也参考此规则。

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「数据第二列次值默认均留空」 | `bar-line-dual-axis` 模板 `default_config.data.rows` 中所有行的 `growth` 改为 `null`；新建实例打开设计器时次值列全部为空 | backend registry / frontend | 单测断言默认配置 growth 全空；前端测试 |
| C2 | 「第二列第一行次值默认不能填入」 | 设计器数据表第 1 行次值单元格禁用（UI 禁止输入），后端 `validate_config` 对第 1 行 `growth` 非空返回 400 | frontend designer / backend validate | 单测 + 前端单测 |
| C3 | 「如果填入第二列次值，则对应主值随之变动」 | 设计器中填写第 i 行次值（增速）后，该行主值按派生公式联动重算（公式口径见未决问题 Q1）；联动结果实时体现在预览 | frontend designer | 前端单测（填次值 → 主值变化） |
| C4 | 「把主动修改的和受影响的值进行区分」 | 设计器数据表中，用户直接编辑的值与因联动自动重算的值有可见区分（视觉标记，口径见未决问题 Q2）；保存的 config 不携带区分标记，仅编辑期提示 | frontend designer | 前端单测（联动后受影响单元格带标记） |
| C5 | 「其他图表也参考此规则」 | 其余模板（水平堆叠条形图、水平分组条形图）凡存在派生关系的单元格遵循同一规则：默认留空、禁填位禁止、填写联动并标记；无派生关系的模板行为不变（口径见未决问题 Q3） | frontend designer / backend | 单测 + 前端测试 |

## 未决问题

- [x] Q1：派生公式 → **次值ᵢ为同比增速：主值ᵢ = 主值ᵢ₋₁ × (1 + 次值ᵢ/100)**，填次值改变本行主值，与渲染端「留空按主值推算次值」互逆（需求方确认，2026-10-28）。
- [x] Q2：区分方式 → **受影响单元格底色高亮 + 悬浮说明**（「由次值联动重算」），仅设计器编辑期显示，不写入保存数据（需求方确认，2026-10-28）。
- [x] Q3：适用范围 → **仅双轴模板（bar-line-dual-axis）落地**；堆叠 / 分组模板行为不变，联动规则作为模式供未来含派生列的模板遵循（需求方确认，2026-10-28）。
- [x] Q4：反向联动 → **直接修改主值ᵢ（i≥2）时，该行次值自动重算**（次值ᵢ = (主值ᵢ/主值ᵢ₋₁ − 1) × 100），重算结果按 C2/C4 标记为受影响值（需求方确认，2026-10-28）。
