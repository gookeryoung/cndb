## 需求原句（逐字）

> 在 cndb 项目里完善 Markdown 导出能力（PDF、DOCX 等格式），重点解决导出结果与页面预览不一致、以及文字溢出这两类 bug。
> 请先摸清现有导出链路（前端预览渲染、后端导出实现、所用的渲染/转换库与模板），找出导出与预览产生差异的根本原因，再动手修。

排查方向：列表（缩进层级、编号延续、嵌套混排、任务列表、项内段落与换行）、表格（列宽、单元格换行与对齐、长文本 / 长 URL、表头重复、跨页断行、边框内边距）、文字溢出（超长单词与 URL、中英文混排、固定宽度截断、代码块横向溢出）、其他可见差异（字体、间距、标题层级、图片尺寸、页边距）。
