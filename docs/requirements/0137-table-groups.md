# 需求卡片：数据表分组（侧栏与列表均可用，默认不分组）

- 编号：0137
- 来源 / 提出人：用户（会话 2026-11-16）
- 日期：2026-11-16
- 关联 ADR：`docs/adr/0137-table-groups.md`（S2）

> 本卡片是**需求原文与约束编号的唯一副本**：需求澄清后先改这里，再同步 ADR「口径」表。

## 需求原句（逐字）

> 数据表提供分组功能，包括侧边栏和列表均可用，默认不分组。

澄清答复（2026-11-16）：

1. 读法：**数据表分组（表按分组归类）**，不是表内行分组。
2. 其余按默认：owner/editor 管理分组；列表页默认仍平铺（分组为可选开关）；分组参与排序并随工作区备份。

## 可实施约束（C1..C8）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「数据表提供分组功能」 | 工作区级「表分组」：可建组 / 改名 / 删除 / 排序；表可归属一个分组 | `tables/models.py`、迁移、`routers/groups.py` | 接口测试：建组 / 改名 / 重排 / 删除 |
| C2 | 「默认不分组」 | `DataTable.group_id` 可空，建表默认为空；表列表页默认平铺，分组为显式开关且不跨会话记忆；删除分组后组内表回落未分组（不删表）；「未分组」是系统占位分组行（`is_ungrouped`），参与分组排序、可位于任意分组之间 | 迁移、`TablesList`、`MainLayout` | 单测：默认平铺、删除后回落、未分组可排前 |
| C3 | 「侧边栏…可用」 | 侧栏有分组时按分组标题展示表（含「未分组」占位）；无分组时与改造前完全一致；折叠态保持平铺；owner/editor 可在侧栏拖拽分组标题调整分组顺序（含未分组位置） | `layouts/MainLayout.tsx` | 单测：分组标题 / 未分组顺序 / 拖拽提交新顺序 / 无分组平铺 |
| C4 | 「列表…均可用」 | 表列表页提供「分组显示」开关：关闭=平铺（默认），打开=按组分节；分组内可拖拽排序，其余表位置不变 | `pages/workspace/TablesList.tsx` | 单测：开关、分节、组内拖拽 |
| C5 | （权限） | 分组成员可读；建组 / 改名 / 排序 / 删除要求 EDITOR；跨工作区分组拒绝；表分组操作沿用表的 `EDIT_SCHEMA` | `routers/groups.py`、`routers/tables.py` | 接口测试：viewer 403 / 跨工作区 400 |
| C6 | （唯一性） | 分组名工作区内唯一、去首尾空白、1..80 字符 | `routers/groups.py` | 接口测试：空名 / 超长 / 重名 400 |
| C7 | （备份） | 分组随工作区归档备份导出与恢复；旧版备份无分组键时按未分组处理；v8 JSON 出口保持旧结构 | `workspace_backup.py`、`workspace_restore.py`、`backup_io.py` | 接口测试：归档往返 / 载荷结构 |
| C8 | （兼容） | 无迁移数据回填（存量表 group_id 为空）；不改变表 CRUD / 记录读写口径；样式走 `--cn-*` token | 全仓 | `make flow` + 前端单测 |

约束编号在实现中原样引用；不重编号、不合并。
