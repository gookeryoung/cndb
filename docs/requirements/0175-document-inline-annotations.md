## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 正文内批注 | 批注锚定正文中的一段文本（TextQuote + 位置偏移），而非整篇评论；锚点字段含 `quote / prefix / suffix / start_offset / end_offset` 与锚定版本号 | `documents` 插件 | 单测：同 quote 不同位置可区分；锚点随版本号落库 |
| C2 | 评论线程 | 一条根批注可挂多条回复；根批注可「解决 / 重开」，回复不可单独解决；删除根批注级联删回复 | 同上 | 单测：回复计数、解决状态、级联删除 |
| C3 | 谁可以批注 | 对文档有 READ 的成员（含 viewer）可新建根批注与回复；根批注作者或 owner/editor 可解决 / 重开；作者可删自己的，owner/editor 可删任意 | API 单测 | 单测：viewer 可批注但不可删他人；solution 权限 |
| C4 | 可见性（H33） | 批注继承文档可见性：文档不可见 → 所有批注端点 404；批注不跨工作区 | API 单测 | 单测：他人草稿的批注 404 |
| C5 | 版本变化 | 批注记录锚定版本号；正文更新 / 回滚后按 quote 重定位，失败标 `orphaned` 并在面板「失效批注」分区展示，不自动删除 | 服务层 | 单测：改动后能重定位；删除原句后变 orphaned |
| C6 | 游客与导出 | 游客分享页不展示批注、不提供批注入库；Markdown / Word / PDF 导出不包含批注 | 分享 / 导出 | 单测：分享载荷无批注；导出产物无批注文本 |
| C7 | 前端 | 阅读 / 编辑态选中文本出现「批注」浮动入口；右侧抽屉列出批注与回复，支持跳转高亮；文档头部显示未解决计数；移动端抽屉全屏 | 前端 | 组件测试 + e2e |
| C8 | 通知边界 | 本期不做站内通知 / @ 提醒（通知表已在迁移 `2c3d4e5f6a70` 删除）；仅文档内计数徽标 | — | 需求方确认（见未决问题） |
| C9 | 测试与文档 | 后端单测、前端单测、CHANGELOG；ADR 决策表无「待定」后进入评审 | 测试 / 文档 | 定向测试全绿 |
