## 需求原句（逐字）

> 版本历史中，提交信息前增加【提交修改信息】标签。提交修改时，默认填入版本历史中的默认提交信息。

|---|---|---|---|---|
| C1 | 版本历史中，提交信息前增加【提交修改信息】标签 | 版本历史卡片的变更说明行，在非空 `change_summary` 文字前渲染小号灰色标签「提交修改信息」；为空时显示「未填写变更说明」且不显示标签 | frontend VersionsDrawer | 前端单测：有 summary 时标签与文字并存；无 summary 时无标签 |

## 口径（方案）

- 默认提交信息常量 `DEFAULT_CHANGE_SUMMARY = '更新文档'`（随原句「版本历史中的默认提交信息」以固定文案落地，需求方已确认）。
- `openSubmit` 内：`setChangeSummary(prev => prev.trim() === '' ? DEFAULT_CHANGE_SUMMARY : prev)`。
- VersionsDrawer 变更说明行：`{v.change_summary && <span className="cn-vh-summary-label">提交修改信息</span>}{v.change_summary || '未填写变更说明'}`，新增 `.cn-vh-summary-label` 小号次要色样式。
