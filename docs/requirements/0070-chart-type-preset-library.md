## 需求原句（逐字）

> 在当前文档编辑功能中，为图表模块扩展支持的图表类型与预设模板库。具体要求如下：
> 1. 新增至少10种以上常用专业图表类型，覆盖折线图、柱状图、饼图、面积图、散点图、雷达图、漏斗图、仪表盘、树状图、热力图等主流业务场景所需类型
> 2. 为每类图表配套3-5套经过视觉优化的预设模板，包含不同配色方案、布局样式和数据展示风格，适配商务汇报、数据分析、项目总结等不同文档使用场景
> 3. 确保新增图表类型与模板能够直接插入文档，支持数据一键导入、样式实时编辑调整
> 4. 保持图表功能的兼容性，不影响现有已插入图表的正常显示和编辑
> 5. 完成扩展后进行功能测试，验证所有新增图表类型和模板的渲染效果、交互操作均正常可用，无样式错乱或功能异常问题

## 口径（方案落点，S1 不另出 ADR）

- **载体**：预设 = 注册表模板条目（同布局函数、不同 default_config），不引入嵌套 preset 概念；设计器 / 插入弹窗 / ETag / 校验全部按既有 `template_key` 通道工作，零接口契约变更（`templates_payload` 增量字段 `row_kind` / `style_fields`，字段只增不改）。
- **行结构**：`ChartTemplate` 新增 `row_kind`（dual-axis / series / value / xy）与 `labels_from_default`；旧 3 模板走原归一分支，行为逐字节不变。
- **样式**：新模板 config 增量 `style` 节（布尔 / 选项开关，如 donut / stacked / showValues / fill / showTrend），按 `style_fields` 声明归一与生成表单；旧模板无 style 节，归一输出形状不变。
- **渲染**：新布局集中在 `layouts.py`（图元 / 工具下沉 `primitives.py` 供 render.py 与 layouts.py 共用，render.py 保持门面再导出）；SVG / PNG 写端为 path 增加填充能力（面积 / 雷达 / 饼图扇形以 M/L 折线近似圆弧，两端写端零解析分叉）。
- **分类**：新增「趋势分析」「分布关联」「综合评价」一级分类，「结构构成」补齐二级（饼图 / 树状图 / 漏斗图），「对比-柱形」纳入纵向柱状图；空分类不输出的既有规则不变。
