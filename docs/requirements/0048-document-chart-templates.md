## 需求原句（逐字）

> 重大功能增强：需要为文档增加可视化图形功能。采取内置模板和用户自定义的设计。按照类别、图形模板两个层级进行管理，用户可以选取特定模板，在此基础上设计对应图形，并且能够在文档中进行引用显示。请参考以上三个可编辑的HTML，设计首批模板。

附注（参考样例，非需求原文）：用户同会话上传三份自包含可编辑 HTML 图表页：

1. `产业营业收入与增速(含预测).html` —— 柱（双轴双色调实际/测算）+ 折线（右轴增速），含规划期分界带、图例、轴下区间说明、数据表 / 图表文案双编辑区、SVG / PNG 导出；
2. `产业营业收入结构变化.html` —— 水平堆叠条形（行 = 年份，系列 = 业务构成），含合计标签与图例；
3. `关键环节本地配套率现状与2030年目标.html` —— 水平分组条形（类别 × 现状 / 目标两组）。

三者共同形态：纯 SVG 绘制、无外部依赖、数据与文案集中在 CONFIG、数据表即改即重绘。

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「为文档增加可视化图形功能」 | 文档正文可嵌入图表，预览（编辑器 / 查看模式）与导出（md / docx / pdf）中真实渲染为图形，而非占位文本 | documents 插件（后端 + 前端 + 导出链路） | 接口层测试 + 前端单测 + e2e |
| C2 | 「采取内置模板和用户自定义的设计」 | 模板为**代码内置**注册表（不可由用户创建 / 修改模板本体）；用户自定义产物是「图表实例」：基于某模板录入数据、修改图表文案与配色后保存 | documents 插件 | 模板清单接口只读；实例 CRUD 校验 template_key 合法 |
| C3 | 「按照类别、图形模板两个层级进行管理」 | 管理结构固定两级：类别（一级分组）→ 图形模板（二级条目）；类别与模板均在代码注册表中定义，接口按两级返回；实例按所基于的模板归入类别 | documents 插件 | 模板清单接口结构测试 |
| C4 | 「用户可以选取特定模板，在此基础上设计对应图形」 | 前端提供「类别 → 模板」选择与图表设计器：按模板的数据 schema 生成可编辑数据表 + 图表文案面板，编辑期间实时预览渲染结果；保存为图表实例 | 前端 documents 页面 + 后端渲染接口 | 前端单测（选择 / 编辑 / 保存 / 插入流程） |
| C5 | 「能够在文档中进行引用显示」 | 文档正文以**独占段落占位符** `{{chart:<图表ID>}}` 引用实例；预览与导出共用同一后端渲染结果；引用失效（图表被删 / 跨工作区）降级为占位文字，不阻断整篇 | 前端引用组件 + 导出解析器 | 解析 / 降级用例（前端 + 后端同构样例） |
| C6 | 「请参考以上三个可编辑的HTML，设计首批模板」 | 首批内置 3 个模板，图形形态 / 可编辑维度对齐三份参考 HTML：①柱线组合图（双轴 · 含规划期分界）；②水平堆叠条形图（结构构成）；③水平分组条形图（现状与目标对比） | 模板注册表 + 渲染器 | 渲染快照测试（SVG / PNG 关键元素断言） |
| C7 | 隐含（数据口径与参考 HTML 一致） | 实例数据手工录入并随实例持久化（含派生值自动计算，如测算期增速 / 合计），不绑定数据表实时数据 | documents 插件 | 渲染器单测（派生值正确性） |
| C8 | 隐含（权限与既有文档能力一致） | 图表实例随工作区走：成员可读可引用，创建 / 修改 / 删除需 owner / editor；导出按导出发起人权限渲染；**游客分享页免登录渲染图表**（token 鉴权，且仅限该分享文档正文实际引用的图表 ID） | documents 插件权限层 + 公开分享路由 | 接口层权限用例（含匿名 render） |
| C9 | 隐含（既有功能零回归） | 既有 `{{table:…}}` 引用、图片插入、导出契约、文档双轨写入全部不受影响；无图表引用的文档行为逐字节不变 | 全链路 | 既有导出 / 编辑器测试全绿 |

约束编号在 ADR 中原样引用；不重编号、不合并。
