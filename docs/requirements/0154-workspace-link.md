## 需求原句（逐字）

> 4默认一对一，可考虑引用设计，但是权限只有拥有团队有；5按建议

ADR 0153 决策记录 D11（2026-11-25 人工确认后定稿）据此把「跨工作区数据」留到 P3：

> 本期不做；需要跨工作区数据汇总时走 P3「工作区链接」另立 ADR

本次立项的生产场景：**总部要汇总各部门工作区里的表**（部门各自维护自己的工作区，总部不想为此把数据搬到一处，也不想给总部人员开一堆写权限）。

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「需要跨工作区数据汇总」 | 提供**只读引用**：消费方工作区可引用另一工作区的一张表（或该表的一个视图），以只读网格查看并导出 CSV；不做数据搬迁、不做写入 | `tables` + `workspaces` 插件 | 接口测试：读 200 / 写路径一律 404 或 405 |
| C2 | 「权限只有拥有团队有」（0153 C5 的延伸） | 授权由**源工作区所有者**逐条批准（发起 → 批准 / 拒绝），链接绑定到期时间；到期立即失效 | `workspaces` 插件 | 接口测试：未批准 404、过期 404、拒绝后 404 |
| C3 | （隐含，H15 天花板） | 链接**不新增授权主体**：取数判定 = 当前用户在**源工作区**的 `resolve_capabilities().data_role`；行级规则（ADR 0004）与字段隐藏照旧生效 | `tables/services/core/row_access.py`、`workspaces/permissions.py` | 判定层单测：源工作区无读权限 → 403 / 行级规则外行不可见（H15/H17 不变） |
| C4 | （隐含，单向） | 链接只读：不提供增删改行、批量、导入、修改申请、字段 DDL 等任何写路径 | `tables` 插件 | 接口测试：对链接的写入口全部不可达 |
| C5 | （隐含，可解释） | 列表与详情必须展示**授权来源**（源工作区、批准人、到期时间、当前是否可读）；不可读时给可执行下一步（联系源工作区拥有者） | 前端 | 单测 + e2e 断言文案 |
| C6 | （隐含，无泄露） | 无权 / 已撤回 / 已过期 / 源表已删统一 **404**，不区分原因（沿用 ADR 0004 I6 口径） | `workspaces` 插件 | 接口测试 |
| C7 | （隐含，不级联） | 链接表不可再被链接、不可作为 lookup 源、不可进入分析页数据源、不可被文档 `{{table:}}` 引用（MVP 边界），避免权限链式推断 | 全局 | 接口测试 + ADR 决策记录 |
| C8 | （隐含，备份边界） | 链接**不进工作区备份**（跨环境 id 无意义）；源工作区 / 源表删除时级联清理 | `workspaces/services/backup_io.py` | 备份往返测试：导出 JSON 不含链接；删除源表后消费方条目随之消失 |
