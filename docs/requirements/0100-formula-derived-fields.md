## 需求原句（逐字）

> 数据表，字段编辑，增加新建派生字段功能，允许根据已有字段按公式、函数生成其他字段内容

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 「字段编辑，增加新建派生字段功能」 | 字段类型新增 `formula`（中文「派生字段」），字段管理新建下拉可选；可配置公式与小数位；已有字段不能切换为派生字段，派生字段也不能切换为其它类型（避免误删物理列） | `field_types/formula.py`、`routers/fields.py`、`FieldManager` | 接口层：创建成功 201 / 类型切换 400；前端：新建表单可选「派生字段」 |
| C2 | 「根据已有字段按公式、函数生成」 | 公式用 `[字段名]` 引用本表字段；保存时校验语法与引用存在；支持 analytics 公式引擎的标量 / 聚合 / 窗口函数白名单 | `services/core/formulas.py`、`routers/fields.py` | 单测：非法语法 / 不存在字段 400；合法公式可保存 |
| C3 | 「生成其他字段内容」 | 派生字段不落物理列，读取行时按公式实时计算并附在行响应（列表 / 单行详情一致）；lookup 先解析、formula 后计算，formula 之间按字段顺序可互相引用 | `services/core/records.py`、`services/core/formulas.py` | 单测：金额 / 数量 → 单价 3.33；更新数量后重新计算 |
| C4 | （只读） | 派生字段写入一律忽略，不进入物理列；网格 / 行详情不可编辑，整行回传公式值不会覆盖计算 | `field_types/formula.py`、前端 `isReadonlyField` / `READONLY_VIRTUAL_FIELD_TYPES` | 单测：PATCH 回传 999 → 仍按公式计算 |
| C5 | （错误容忍） | 公式运行期异常 / 引用字段失效时该字段回退 None，不拖垮整行 / 列表读取 | `formulas.py` | 单测 / 代码审查 |
| C6 | （前端） | 字段管理器新增派生字段配置（公式 + 小数位 + 可用字段提示）；字段类型元数据、默认值控件、行详情只读口径同步 | `typeConfigPanel.tsx`、`fieldTypeMeta.ts`、`RowDetailDrawer.tsx` | 前端单测：新建派生字段提交 formula config |
| C7 | （工程口径） | 无数据库迁移；CHANGELOG / CONTEXT / ADR 索引同步；后端 / 前端全量测试通过 | 文档 | `make flow` / `make check-fast` |

约束编号在实现中原样引用；不重编号、不合并。
