## 需求原句（逐字）

> 当前工作区导出功能并不能完全备份和恢复所有信息，请进行重构设计，需要具备工作区所有内容的备份和恢复。

## 可实施约束（C1..Cn）

| # | 需求句（原文片段） | 可实施约束 | 涉及模块 | 验收方式 |
|---|---|---|---|---|
| C1 | 完全备份 | 工作区级备份必须覆盖该工作区在数据库中的**全部**持久化数据（详见「现状影响面」清单），不遗漏文档历史版本、草稿、回收站、表成员、数据源会话与游标、附件等现有 v8 备份未覆盖项 | `workspaces` plugin | 往返测试：导出→清库→导入，逐表逐字段比对一致 |
| C2 | 完全恢复 | 恢复后工作区功能与备份时点一致：表/视图/行/权限、文档树+版本历史+草稿+回收站、同步任务可运行、图表可渲染、附件可访问 | `workspaces` + 各 plugin | e2e + 单测断言各对象 id/内容/引用关系 |
| C3 | 重构设计 | 备份格式升级为新版本（v9+ 或新格式），旧版备份文件仍可导入（向后兼容） | `backup_io.py` | 旧版本备份样本导入回归测试 |
| C4 | 所有内容 | 附件等二进制内容纳入备份（现 JSON 方式不可行时允许改归档格式，需 ADR 决策） | `workspaces` + `files` | 往返测试覆盖附件文件 |

## 现状影响面（候选，待 ADR 核实）

当前工作区 JSON 备份（version 8，`workspaces.py:576-585`）已覆盖：工作区 meta、表结构/字段/视图/行、表级+行级权限、link 关联、文档标签、文档树+最新正文、同步任务（会话只记名称）、文档图表实例。

| # | 遗漏数据 | 候选位置 | 备注 |
|---|---|---|---|
| 1 | 文档历史版本 | `plugins/documents/models.py:135` | 明确不含历史版本（`workspaces.py:493`） |
| 2 | 文档草稿 | `plugins/documents/models.py:234` | 含 diff（req 0057） |
| 3 | 回收站（软删除文档） | `workspaces.py:501` | 导出时显式过滤 `is_deleted` |
| 4 | 文档置顶 / 分享 | `documents/models.py:322,202` | |
| 5 | 文档议题+评论+事件 | `documents/models.py:339-419` | |
| 6 | 表成员、审计日志、导入/治理任务 | `tables/models.py:452-602` | |
| 7 | 数据源会话（含密钥）与 entrant cursor | `datasource/models.py:60,181` | 现仅按名称引用，密钥不导出（`workspaces.py:561`） |

另存在**系统级** CLI 备份（`cli/backup.py`，SQLite 全库 + uploads 的 tar.gz），与工作区 JSON 备份定位不同：前者全库快照含所有工作区与用户，后者单工作区跨库可移植。本需求针对工作区级备份。

## 未决问题（已全部有结论，2026-10-31 需求方确认）

- [x] Q1 恢复语义：**支持覆盖恢复到原工作区**（原地还原到备份时点，保留原工作区 id/成员/路径引用）；「导入为新工作区」作为既有能力保留兼容。
- [x] Q2 数据源会话密钥：**纳入备份**，提供可选开关（默认导出，可关闭）。
- [x] Q3 流水类数据：**不备份**（表审计日志、数据源同步运行历史、议题事件流）。
- [x] Q4 备份格式：**改为归档格式**（manifest.json + 数据文件 + 附件原文件）；单 JSON 仅保留旧版导入兼容层。
- [x] Q5 个人级数据边界：**沿用 ADR 0019 口径不导出**（`llm_user_config` 个人配置、`llm_run` 运行记录）。默认决策，未单独确认，待复核。
